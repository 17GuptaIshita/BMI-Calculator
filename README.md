<h1>🩺 BMI Calculator</h1>
<p>
  A <strong>Body Mass Index (BMI)</strong> calculator is a simple yet essential tool for assessing whether your body weight is within a healthy range based on your height and weight. This tool not only computes your BMI but also categorizes the result into <em>Underweight</em>, <em>Healthy</em>, <em>Overweight</em>, or <em>Obese</em>.
</p>

<h2>🚀 Features</h2>
<ul>
  <li>Instant BMI calculation</li>
  <li>Clear categorization of BMI status</li>
  <li>Responsive and clean user interface</li>
  <li>Lightweight and easy to use</li>
</ul>

<h2>🛠️ Technologies Used</h2>
<p>This project is built with the following technologies:</p>
<ul>
  <li>🔧 <strong>HTML5</strong> – Markup and structure</li>
  <li>🎨 <strong>CSS3</strong> – Styling and responsive design</li>
  <li>⚙️ <strong>JavaScript</strong> – Core logic and interaction</li>
  <li>🗂️ <strong>Git & GitHub</strong> – Version control and collaboration</li>
  <li>🌐 <strong>Vercel</strong> – Seamless deployment and hosting</li>
</ul>

<h2>🧠 How It Works</h2>
<ol>
  <li>Input your height and weight</li>
  <li>Click the calculate button</li>
  <li>Instantly view your BMI and its category</li>
</ol>

<p><em>Empowering health through intuitive tools.</em></p>
